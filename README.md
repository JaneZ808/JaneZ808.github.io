# 张靓颖 Jane Zhang · 明星资料站

一个纯静态、零依赖的明星资料站，结合张靓颖的作品特点做了模块扩展。

## 目录结构

```
zhangliangying/
├── index.html              # 主页面（单页锚点导航，含 CSP 安全头）
├── assets/
│   ├── css/style.css       # 全部样式（含深浅两套主题变量）
│   ├── img/                # 照片素材（hero / avatar / profile / albums 真实专辑封面 / osts / globals）
│   └── js/
│       ├── data.js         # 数据层：所有人物资料都在这里，改内容只需改这一个文件
│       └── main.js         # 渲染与交互逻辑
├── .nojekyll               # 禁用 GitHub Pages 的 Jekyll 处理
├── .gitignore
└── README.md
```

## 页面模块

| 模块 | 说明 |
| --- | --- |
| Hero | 首屏标题、身份、代表语录、核心数据 |
| News 最新动态 | 2025—2026 年重要动态卡片 |
| Profile 个人档案 | 16 项基本信息参数表 + 个人简介 |
| Journey 星路历程 | 1984—2026 双列时间线 |
| Music 音乐作品 | 7 张正式录音室专辑（真实封面 + 完整曲目）；第八张专辑先行曲动态单独呈现；EP / 迷你专辑 / 现场 / 精选 / 未发行先行曲共 14 张作品保留详情页作资料存档，不计入正式专辑；影视金曲 OST、英文作品 |
| Tour 巡回演唱会 | 7 轮巡演，含「追」进行中标记 |
| Awards 荣誉记录 | 29 条奖项，可按 5 类筛选 |
| Screen 影像与舞台 | 参演影视/音乐剧 + 常驻综艺 |
| Contact 聆听与关注 | QQ音乐/网易云/酷狗/微博直达 |

交互：吸顶导航高亮、滚动进度条、滚动渐显、深浅色主题切换（记忆偏好）、移动端折叠菜单、专辑/奖项筛选、回到顶部。
